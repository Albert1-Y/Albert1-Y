## 🚀 Proyectos Destacados

### [WiñayXP · Plataforma de gamificación educativa](https://github.com/Albert1-Y/WinayXp-frontend)
Sistema integral para incentivar la participación estudiantil mediante dinámicas de gamificación.

- **Frontend (React + Vite + Chart.js)**: Dashboard modular con roles para estudiantes, tutores y administradores, escaneo de QR y analíticas en tiempo real.  
- **Backend (Node.js + Express + PostgreSQL)**: API documentada con Swagger, autenticación híbrida (JWT + OAuth Google), gestión de sesiones y exportación de reportes.  
- **Rol**: Co-diseño de la arquitectura fullstack, implementación de vistas, lógica de ranking y protección de rutas.

[Repositorio Frontend](https://github.com/Albert1-Y/WinayXp-frontend) · [Repositorio Backend](https://github.com/Albert1-Y/WinayXp-backend)

### [Simulación de Péndulo de Foucault](https://github.com/Albert1-Y/Simulacion_foucault)
Aplicación de escritorio en **C++/SFML** que modela la conservación de energía y la precesión terrestre.

- Integración numérica custom (time-step adaptativo) con visualización del rastro de movimiento.  
- Panel de métricas (posición, velocidad, aceleración) y controles de aceleración temporal.  
- Empaquetado con dependencias SFML listas para compilar en Visual Studio.

---

### [GestorBD2 · Simulador de disco y registros](https://github.com/Albert1-Y/Gestor_BD2)
Herramienta educativa desarrollada en **Python + PyQt6** que replica la gestión de registros en un disco virtual.

- Explorador visual de platos, pistas y sectores configurables.  
- Importación desde CSV y carga diferida en estructuras internas.  
- Organización modular (`disco/`, `interfaz/`, `util/`) para facilitar la extensión del motor.

---

### [Cifrado Afín interactivo](https://github.com/Albert1-Y/Algebra_Abstracta-Cifrado_Afin)
Script en **Python** que permite experimentar con el cifrado afín paso a paso, mostrando el cálculo del m.c.d. y las claves generadas.

- Verificación de coprimalidad para el parámetro `a`.  
- Opciones de encriptado y desencriptado con retroalimentación inmediata.  
- Documentación ligera que contextualiza el algoritmo.
